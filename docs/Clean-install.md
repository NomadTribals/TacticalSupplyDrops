# Installation and upgrade

1. Finish pending deliveries and collect cargo before upgrading. Close the game and SPT server, then back up the profile.
2. Extract this archive into the SPT game folder containing EscapeFromTarkov.exe. Merge the BepInEx and SPT_Runtime folders.
3. Replace existing TacticalSupplyDrops program files. Remove duplicate older loose Logistics DLLs if present. Preserve BepInEx/config/TacticalSupplyDrops and existing player settings.
4. Keep TSD Technologies 1.2.0 and Anvil WebOverlay 1.12.0 or newer installed. Start the server and game normally.

Do not extract the archive only into SPT_Runtime. This package contains Logistics only; the tablet and Field OS are installed separately.

For an older standalone 2.x installation, remove the old standalone program files before installing Technologies and Logistics. Back up settings and order state first. Version 2.1.0 remains the older standalone option.
